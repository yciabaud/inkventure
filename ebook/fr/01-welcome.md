# Bienvenue

[Ouvrir Inkventure]({{host}}){.open-app}

Touchez le lien ci-dessus, le Wi-Fi allumé (la liseuse peut demander une confirmation) : l'application s'ouvre
dans son navigateur web.

Ce livre ouvre la porte de la fiction interactive : des histoires dont vous décidez la suite en écrivant ce que vous
voulez faire. Vous pouvez le lire partout, et jouer gratuitement à chaque jeu qu'il présente sur la liseuse que vous
tenez en main.

Inkventure est une application web gratuite conçue pour les écrans à encre électronique. Ni compte ni installation :
ouvrez son adresse dans le navigateur de votre liseuse et choisissez une histoire.
