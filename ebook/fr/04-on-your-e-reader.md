# Inkventure sur votre liseuse

1. Activez le Wi-Fi.
2. Ouvrez le navigateur web (sur certaines liseuses, il est dans le menu, parfois sous « expérimental »).
3. Allez à l'adresse <{{host}}>.

Les liens de ce livre ouvrent directement le jeu : suivez-en un, confirmez l'ouverture de la page web, et l'histoire
commence. Sur un appareil sans navigateur, scannez plutôt le code QR de la fiche avec un téléphone.

Votre progression est gardée dans le navigateur de la liseuse, sur l'appareil même : rien n'est envoyé nulle part.
Effacer les données du navigateur l'efface aussi.
