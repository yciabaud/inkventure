## User story

As a reader, I want a calm, Kindle-like interface with big tap targets so that the app is comfortable on e-ink.

## Scope

- Base CSS: typography (bundled subset serif + sans, fallbacks), black/white palette, spacing scale, 48 px tap targets, no transitions.
- Components: TopBar, IconButton, Button, Pager (‹ Prev n / N Next ›), Cover (IFDB image in grayscale + generated typographic placeholder), Dialog/Menu, EmptyState, ErrorPage.
- Hash router with routes `#/home`, `#/library`, `#/game/:tuid`, `#/play/:tuid`, `#/settings` (placeholder screens), query params support, 404 → Home.
- "Refresh screen" utility (full black/white flash).
- Icons as inline SVG (own drawings, not Amazon's).

## Acceptance criteria

- [ ] All placeholder screens reachable through the top bar and the back button.
- [ ] Legacy bundle still passes es-check; stylelint bans respected.
- [ ] Visual check at 600×800 and 1072×1448: no horizontal scroll, no element smaller than 48 px tappable.

## Required tests

**Unit (Vitest)**

- Router: parse/serialise paths and query strings, unknown route fallback.
- Typographic cover: deterministic output for a title/author.

**E2E (Playwright)**

- Navigate between all screens by tapping; back button returns to previous screen; deep link `#/settings` cold start works.

Plus the global gates: lint, `es-check es5` on the legacy bundle, CI green.

## Out of scope

- Real screen content.
