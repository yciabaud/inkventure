## User story

As a reader, I want a calm, Kindle-like interface with big tap targets so that the app is comfortable on e-ink.

## Scope

- Base CSS: typography (bundled subset serif + sans, fallbacks), black/white palette, spacing scale, 48 px tap targets, no transitions.
- Components: TopBar, IconButton, Button, Pager (‹ Prev n / N Next ›), Cover (IFDB image in grayscale + generated typographic placeholder), Dialog/Menu, EmptyState, ErrorPage.
- Hash router with routes `#/home`, `#/library`, `#/game/:tuid`, `#/play/:tuid`, `#/settings` (placeholder screens), query params support, 404 → Home.
- "Refresh screen" utility (full black/white flash).
- Icons as inline SVG (own drawings, not Amazon's).

## Acceptance criteria

- [x] All placeholder screens reachable through the top bar and the back button.
- [x] Legacy bundle still passes es-check; stylelint bans respected.
- [x] Visual check at 600×800 and 1072×1448: no horizontal scroll, no element smaller than 48 px tappable.

## Required tests

**Unit (Vitest)**

- Router: parse/serialise paths and query strings, unknown route fallback.
- Typographic cover: deterministic output for a title/author.

**E2E (Playwright)**

- Navigate between all screens by tapping; back button returns to previous screen; deep link `#/settings` cold start works.

Plus the global gates: lint, `es-check es5` on the legacy bundle, CI green.

## Out of scope

- Real screen content.

## Notes & decisions

- **Components live in `src/ui/`** (not listed in the original SPEC §9 layout, now added): `TopBar`, `IconButton`,
  `Button`/`LinkButton`, `Pager`, `Cover` (+ `cover.ts`), `Dialog`/`Menu`, `EmptyState`, `ErrorPage`, `icons.tsx`,
  `refreshScreen.ts`. Styles: `src/styles/base.css` (tokens documented in its header comment) and `src/styles/ui.css`.
- **Navigation uses plain `<a href="#/…">` links** (top bar, pager, buttons) rather than JS handlers, so taps, the
  back button and deep links all go through the browser's own hash history. `Pager` takes an `hrefFor(page)`.
- **Router** (`src/app/router.ts`): `parseHash` / `formatHash` / `parseQuery` / `formatQuery`, `useLocation()` and
  `navigate()`. Query keys are sorted for stable URLs. Unknown routes and non-canonical hashes are replaced with
  `location.replace()` (no extra history entry); unknown → `#/home`.
- **Fonts**: Literata (400, 400 italic, 700) and Source Sans 3 (400, 600) from `@fontsource`, latin subset, woff2 +
  woff (≈ 20–27 KB per file, loaded only when used), with Georgia / Arial fallbacks.
- **Autoprefixer** added (PostCSS) with a `browserslist` matching the legacy targets, for `-webkit-box` flexbox on old
  WebKit. stylelint now also bans `inset` (too new) and enforces BEM class names.
- **Typographic cover**: FNV-1a hash of normalised title + author picks one of 5 variants (frame, band, inverse,
  rules, corner) and an ornament; long titles use a smaller size. IFDB images get `filter: grayscale(1)` and fall back
  to the typographic cover on error.
- **Dialog** focuses the panel itself (no focus ring on the close button), closes on Escape / backdrop, and restores
  focus on close. The top-bar "Menu" holds **Refresh screen** (black then white full-screen flash, 150 ms each).
- **Strings**: all shell strings already go through a minimal English-only `t()` in `src/i18n/` so no string needs
  moving later; S0.5 adds French, locale detection and plurals (its scope was updated accordingly).
- **Placeholders**: Library shows a demo `Pager` (`?page=`, 3 pages) and a link to `#/game/sample` so navigation can
  be tested end to end; both go away with S3.1. The reader keeps the top bar visible for now (it will hide behind
  the top tap zone in S1.1).
- **E2E** (`tests/e2e/shell.spec.ts`): tap navigation through every screen and back, `#/settings` cold start,
  unknown-route fallback without history entry, Refresh screen, and on every screen: no horizontal overflow and every
  visible link/button ≥ 48 × 48 px, on both e-reader sizes and desktop.
