## User story

As a reader, I want a game's language in the catalogue to be the language of the file Inkventure plays, so that a
game listed in French really is in French when I open it.

## Background

Found playing *Les lettres du Docteur Jeangille* (`rpis77r72fg8228`): listed in French (and so on the French Home
shelf), it opens in English.

- IFDB's language field is `French, English (fr, en)`; `normalizeLanguage` (`scripts/catalog/resolver.ts`) keeps the
  first language, `fr`.
- The bilingual version is only on itch.io (not downloadable by the app). The file the resolver picks, the Spring Thing
  zip on the IF Archive, is described on IFDB as "Spring Thing 2024 version, at the IF Archive. **(English only.)**"
- In the catalogue of 2026-09-30 (3,000 games), 44 games list several languages on IFDB; 3 have a chosen file whose
  description says "English only": Jeangille (wrongly `fr`), *The good people* and *Evita Sempai* (already `en`).

## Scope

- **"Only" in the chosen file's description.** When IFDB lists several languages and the description of the download
  the resolver chose names one of them followed by "only" (`English only`, `(English only.)`, `French only`,
  `en français seulement`…; language names in English and in the game's languages, case-insensitive), that language
  becomes the game's language. A description naming a language that IFDB does not list for the game changes nothing.
- **Override by hand.** A `languages` map in a checked-in pipeline file (next to `content-policy.json`'s `exclude`):
  `{ "tuid": { "language": "en", "reason": "…" } }`, applied last, for cases the rule cannot read. Unknown tuids are
  reported, not fatal.
- **Report.** `report.json` and the job summary list the games whose language came from the rule or the override, and
  count the games that keep the first of several languages (to review by hand).
- SPEC §5.2 (how the language is chosen) updated.

**Added by the owner (2026-10-01), in this story:**

- **The language of every file.** Besides "only", a description naming a single language (`Spanish version`,
  `IFComp 2005 version (English)`, `In English`, `Traducido por…`) or, without any, a language tag in the file name
  (`hs_ita.z5`) gives a file's language (found on the record cache: *Lime Ergot*, *Hello Sword*, *Big Fish* and
  *The Sweetest Honey* were listed in a language their file is not in).
- **A file per language.** When IFDB offers files in several of the game's languages (19 games on the record cache:
  *The Awakening*, *Dracula*, *De Baron*, *Filaments*…), the catalogue keeps the best file of each language; the game
  is found under each language (Library filter, facets, Featured lists) and its page lets the reader choose the
  language to play in. Each language version keeps its own saves.

## Acceptance criteria

- [ ] After a Catalogue run, Jeangille is listed in English: not on the French Home shelf, and found by the Library's
      English filter. _The rule gives `en` on its recorded record and on the whole record cache of the `catalog`
      branch (see Notes); to check on the next Catalogue run after merge._
- [x] Games with one language, or several languages and nothing said of their file's language, keep their language
      as now.
- [x] The report lists the changed games, the games with a file per language and the count of multi-language games
      whose file's language is assumed.
- [x] A game with files in several languages is found under each of them in the Library, is featured in each UI
      language it has, and its page offers each language; each plays its own file, with its own saves.

## Required tests

**Unit (Vitest)**

- The rule on recorded IFDB records: Jeangille (`fr, en` + "(English only.)" → `en`), a multi-language game without
  "only" (unchanged), a description naming a language the game does not list (unchanged), a description in French
  ("en français seulement" on an `en, fr` game → `fr`), a single-language game (unchanged).
- The override: applied after the rule, an unknown tuid reported.
- A file's language from its description and its name; files per language on recorded records (Dracula, Hello Sword,
  Tuuli, Lime Ergot); files outside the IF Archive only when readable; index rows, facets, details and their
  validation; Featured lists; game ids, versions and the version a page opens on; the Library filter; games in
  progress under another language.

**E2E (Playwright)**

- The sample's *Cave of Echoes* (French, with an English translation): the language buttons, the page opening on the
  UI language or the one a link names, Play on each language's own file, cached under its own id; the Library finds it
  under both languages.

Plus the global gates: lint, `es-check es5` on the legacy bundle, CI green.

## Out of scope

- Every language of a single bilingual file (a language chosen inside the game): a follow-up if bilingual files turn
  out to be common.
- Detecting a story's language from its text.
- Offering the itch.io version or any other file the app cannot download.
- Other versions in the *same* language (post-competition release vs. competition entry): the best one is kept.

## Notes & decisions

- **Where:** `scripts/catalog/resolver.ts` — `languagesOf` (every language of IFDB's field, as primary subtags),
  `onlyLanguage`, `fileLanguage` (one file) and `planLanguages` (the files of a game), called from `resolve`
  (override, report); `chooseFile` also returns the other usable files. The link field IFDB calls a description is
  `desc`.
- **A file's language**, only for a game IFDB lists in several languages: the description (entities decoded, lower
  case, accents removed) names one of them "only" (`only` / `seulement` / `uniquement` / `solamente` / `soltanto` /
  `nur` after the name, `only in` / `seulement en` / `uniquement en` / `solo en` / `solo in` / `nur auf` before it);
  else it names a single language (English, French and native names, more names so that "Slovak" is not read as
  nothing, and translation words: `traducido` → es, `traduit` → fr, `übersetzt` → de, `tradotto` → it), not one
  preceded by "from"; `bilingual` / `bilingue` / `multilingual` / `both`, or two languages, mean unknown. Without any
  language in the description, a tag in the file name (or the zip's story file): `en`/`eng`, `fr`/`fra`, `es`/`esp`,
  `it`/`ita`… as a separate word after the first one (`hs_ita`, `Lux PL`, not `en.z5`). A language the game does not
  list is ignored.
- **Files per language:** in the resolver's order of preference, the first file of each language; the first file of
  unknown language stands for the first language (in IFDB's order) without a file. The chosen file stays the default
  one when its language is known — so existing saves keep their file; otherwise (*Tuuli*: the preferred file says
  nothing, the others say Spanish and English) the best file in IFDB's first language becomes the default one, and
  the report says the file changed. Files outside the IF Archive are offered only when `--cors` says the app can read
  them; `urlsToCheck` adds them for multi-language games. The picture count (S2.5) is the default file's.
- **Override:** `languages` in `content-policy.json` (`{ tuid: { language, reason } }`, empty for now), applied after,
  sets the default file's language and drops a version in that language; one naming no kept game (unknown, or
  dropped) is listed in `report.json` and warned on the console, not fatal.
- **Report:** `report.json` gains `languages: { changed, versions, assumed, unknownOverrides }`: the games whose
  language is not IFDB's first or whose default file changed (`from`, `to`, `source: file|override`, `detail`,
  `file`), the games with a file per language and their languages, and the count of multi-language games whose
  default file's language is assumed. The job summary shows them after "Kept games, by language".
- **Catalogue files:** index rows gain `lv` (the other languages); `meta.json` facets count each language of a game;
  `games/<tuid>.json` gains `versions: [{ language, file }]`; both are validated. Optional keys: `CATALOG_VERSION`
  stays 1. Featured lists count a game in each of its languages (a curated game gets that language's pitch).
- **App:** a version other than the default file is its own game for storage, id `<tuid>-<lang>` (`gameId` /
  `parseGameId` in `src/storage/keys.ts`; IFDB TUIDs have no `-`): progress, saves, cached file, Home entry, and
  `#/play/<tuid>-<lang>`. Nothing else in storage changed: the readers already key everything by the id they get.
  The game page has a "Language" row of buttons (`aria-pressed`, ≥ 48 px) when there is more than one file; it opens
  on the language the link names (`#/game/<tuid>-<lang>`), else the one last played, else the UI language, else the
  default file's. A cover of a version is the game's; the Featured shelf leaves a game out when any of its versions
  is in progress; the Library's language filter matches any of a game's languages.
- **Checked on the real records** (the 5,345 records of `cache/viewgame` on the `catalog` branch, every format
  enabled, every host assumed readable): 7 games change language (Jeangille `fr → en`, *Hello Sword* `it → en`,
  *Big Fish* `zh → en`, *The Sweetest Honey* `es → en`, *Lime Ergot* `en → es`, *Lux* `en → pl`, *Tuuli* `es` with
  another file), 15 games get a file per language, 39 multi-language games play a file whose language is assumed.
- **Fixtures:** `tests/fixtures/ifdb-records/` holds real records (see its README). The French "seulement" case and a
  description naming a language the game does not list are edits of Jeangille's record in the test. The sample's
  *Cave of Echoes* is now in French with an English translation, so the English Featured shelf of the sample has 4
  games and Play from its page in English opens `#/play/fxcave0000000003-en` (e2e tests updated).
- **Follow-ups (not done):** a per-file override for files the rule cannot read (e.g. *Spider and Web*'s Russian
  translation, "Translated by Vsevolod Zoubarev"; *Blue Chairs*' Russian one, described in Cyrillic); a language
  label on Home cards when both versions of a game are in My adventures.
