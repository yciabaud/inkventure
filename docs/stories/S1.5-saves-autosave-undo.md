## User story

As a player, I want my game saved automatically and in named slots so that I can stop anytime and come back.

## Scope

- Autosave after each turn (Quetzal via engine) into `ik:v1:save:<tuid>:auto`, compressed.
- On opening `#/play/:tuid`, resume from autosave (with transcript tail restored).
- Save… / Restore… dialogs with up to 5 named slots (name, date, turn).
- Undo: engine undo or previous snapshot (10 in memory).
- Restart with confirmation.
- Progress record (turn count, last played, location) for Home.

## Acceptance criteria

- [ ] Reloading the page mid-game resumes at the same turn with the last page of text visible.
- [ ] Storage-full while saving shows a clear message and does not corrupt previous saves.

## Required tests

**Unit (Vitest)**

- Save/restore round-trip through storage (Z fixture), slot management, undo stack.

**E2E (Playwright)**

- Play 3 turns, reload → same state; save in slot, play, restore → earlier state; undo reverts one turn.

Plus the global gates: lint, `es-check es5` on the legacy bundle, CI green.
