## User story

As the maintainer, I want a repeatable device test and automatic budgets so that releases work on real e-readers.

## Scope

- `docs/device-checklist.md`: 15-minute scripted test (home, library filters, play Z/Glulx/Ink, save, reload, export).
- Bundle size budget check in CI (initial JS ≤ 150 KB gz, CSS ≤ 20 KB).
- Release notes template including device results.
