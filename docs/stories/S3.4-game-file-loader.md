## User story

As a player, I want tapping Play to download and start the real game so that the whole catalogue is playable.

## Scope

- XHR arraybuffer download with progress page and timeout; zip extraction when the index says so.
- IF Archive CORS **verified on a Kindle in S0.3** (main site and mirror allow it): download directly; keep the
  SPEC §5.5 fallbacks for files hosted elsewhere.
- Small-file cache in storage (LRU); engine selection by format.
- Error page: retry, open on IFDB, report.

## Acceptance criteria

- [ ] Play on a sample catalogue entry downloads (mocked in e2e) and starts the right engine; failures show the error page.

## Required tests

**Unit (Vitest)**

- Format → engine mapping, cache policy, zip extraction.

**E2E (Playwright)**

- Mocked file route → game starts; mocked 404 → error page with retry.

Plus the global gates: lint, `es-check es5` on the legacy bundle, CI green.

## Out of scope

- Mirroring pipeline beyond what the CORS result requires.
