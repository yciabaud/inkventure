## User story

As a player, I want to play Inform 7 (Glulx) games so that most modern parser IF is available.

## Scope

- Quixe integration through the same Glk bridge, lazy chunk.
- Blorb unpacking (gblorb), images rendered in grayscale, sound ignored.
- Time-slicing of VM execution to keep taps responsive.
- Measure turn latency on a real Kindle for 2–3 games; define the "may be slow" heuristic (feeds S2.2).
- Glulx fixture game in `tests/fixtures/`.

## Acceptance criteria

- [x] Fixture Glulx game playable with saves/undo/chips.
- [ ] Latency measurements recorded in `docs/device-reports/` and the heuristic documented in SPEC §4.5.

## Required tests

**Unit (Vitest)**

- Headless Glulx walkthrough; save/restore round-trip.

**E2E (Playwright)**

- Play fixture Glulx game: command, save, reload resumes.

Plus the global gates: lint, `es-check es5` on the legacy bundle, CI green.

## Out of scope

- Glk features beyond text/status/images (hyperlinks optional, timers ignored).

## Notes & decisions

- **Quixe is downloaded at install**, not vendored (owner's review): it is not on npm (the `quixe` package there is an
  unofficial 2018 repackaging) and its repository has no `package.json`, so a `postinstall` script
  (`scripts/build/fetch-quixe.ts`) fetches Quixe 2.2.6 unchanged from the `quixe-2.2.6` tag, checked against SHA-256
  hashes in `scripts/build/quixe-files.ts`, into `vendor/quixe/` (ignored by git): `quixe.js`, `gi_dispa.js`, and its own
  `glkapi.js` + `gi_blorb.js` (Quixe 2.2 needs the GlkOte 2.3-generation Glk library; the Z-machine keeps
  `glkote-term`'s). Checked build-time patches (`scripts/build/vendor-patches.ts`, tested) make them ES modules, remove
  `window` / `document` / jQuery uses (the Blorb IFmd metadata chunk is skipped), and add time slicing.
- **Engine** (`src/engines/quixe/quixeEngine.ts`, lazy chunk 61 KiB gz): same GlkOte bridge as ZVM (it now also hands
  the Glk library its `Dialog`); `.gblorb` unpacked with Quixe's Blorb decoder; only the current VM reaches the reader,
  a replaced one is `abandon()`ed.
- **Time slicing:** past 100 ms a VM run yields (`setTimeout`) and carries on; so `load` / `restoreState` / `restart`
  resolve when the game first waits for input. The reader shows "The story is thinking…" in the command bar while a turn
  runs (only visible for turns longer than a slice; ZVM turns never show it).
- **Saves:** Quixe's autosave snapshot, with the pending event from `GiDispa.check_autosave` (patched to also allow the
  first prompt, so the opening turn can be undone/resumed like on the Z-machine). The RAM is stored XORed with the
  story's initial RAM: the fixture's state deflates to ~1.5 KB. Quixe's own signature is unusable (it writes hex into a
  `Uint8Array`), so the envelope names the story by its first 64 bytes in hex.
- **Fixture:** `tests/fixtures/glulx/lamp.ulx`, the Lamp at Saltmere compiled for Glulx (portable key prompt), served at
  `#/play/fixture-glulx`; `scripts/fixtures/build-glulx.sh` (needs the 6.12 library with `infglk.h`).
- **Measuring:** `?perf=1` on the reader shows the last turn's time in the status line (and logs it); how to run it is
  in `docs/device-reports/README.md`. The sandbox cannot reach the IF Archive, so no real Inform 7 game was timed
  here: **acceptance criterion 2 waits for a Kindle run** on 2–3 real Glulx games, after which SPEC §4.5 and the
  resolver's `slow` rule (still "every Glulx game") get the measured heuristic.
- **Not done: images** (scope: "rendered in grayscale"). Drawing them needs an image block through the transcript,
  the paginator (sizing before load) and the saved transcript tail: proposed as a follow-up story. Sound is ignored,
  timers ignored as planned.
- **Glulx enabled in the catalogue** (`scripts/catalog/playability.json`: `zcode`, `glulx`), as that file asks for
  "in the same PR as its engine" (first missed, found by the owner looking for Glulx games to test). Real Glulx games
  appear after the next Catalogue run; the sample catalogue gains its Glulx fixture game.
- The e2e test "a format without an engine yet" now uses an ink game (Glulx is playable).
