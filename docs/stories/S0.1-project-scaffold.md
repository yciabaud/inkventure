## User story

As a developer, I want a working TypeScript/Preact project with tests and CI so that every later story starts from a green, Kindle-compatible baseline.

## Scope

- Vite + TypeScript + Preact app rendering a placeholder page.
- `@vitejs/plugin-legacy` producing an ES5 legacy bundle with polyfills.
- Vitest configured (jsdom), one sample test.
- Playwright configured with projects `ereader-small`, `ereader-large` (WebKit + Chromium, touch, reducedMotion) and `desktop` (Chromium); one smoke spec.
- `es-check es5` on legacy output; ESLint + Prettier; stylelint with rules banning `display: grid` and `var()`.
- GitHub Actions workflow: install, lint, unit, build, es-check, e2e (Playwright with the preinstalled browsers / official action).
- npm scripts: `dev`, `build`, `test`, `test:e2e`, `lint`, `check:es5`.

## Acceptance criteria

- [ ] `npm ci && npm run lint && npm test && npm run build && npm run check:es5 && npm run test:e2e` all pass locally and in CI.
- [ ] The repository layout matches SPEC §9 (empty folders get a README or .gitkeep).
- [ ] CI runs on pull requests and on pushes to main.

## Required tests

**Unit (Vitest)**

- Sample test proving Vitest runs with jsdom.

**E2E (Playwright)**

- Smoke: app loads at `/` in every Playwright project with no console errors.

Plus the global gates: lint, `es-check es5` on the legacy bundle, CI green.

## Out of scope

- Deployment (S0.2).
- Any real screen.
