## User story

As a developer, I want a working TypeScript/Preact project with tests and CI so that every later story starts from a green, Kindle-compatible baseline.

## Scope

- Vite + TypeScript + Preact app rendering a placeholder page.
- `@vitejs/plugin-legacy` producing an ES5 legacy bundle with polyfills.
- Vitest configured (jsdom), one sample test.
- Playwright configured with projects `ereader-small`, `ereader-large` (WebKit + Chromium, touch, reducedMotion) and `desktop` (Chromium); one smoke spec.
- `es-check es5` on legacy output; ESLint + Prettier; stylelint with rules banning `display: grid` and `var()`.
- GitHub Actions workflow: install, lint, unit, build, es-check, e2e (Playwright with the preinstalled browsers / official action).
- npm scripts: `dev`, `build`, `test`, `test:e2e`, `lint`, `check:es5`.

## Acceptance criteria

- [x] `npm ci && npm run lint && npm test && npm run build && npm run check:es5 && npm run test:e2e` all pass locally and in CI.
- [x] The repository layout matches SPEC §9 (empty folders get a README or .gitkeep).
- [x] CI runs on pull requests and on pushes to main.

## Required tests

**Unit (Vitest)**

- Sample test proving Vitest runs with jsdom.

**E2E (Playwright)**

- Smoke: app loads at `/` in every Playwright project with no console errors.

Plus the global gates: lint, `es-check es5` on the legacy bundle, CI green.

## Out of scope

- Deployment (S0.2).
- Any real screen.

## Notes & decisions

- **Vite 7, not 8.** With Vite 8 (Rolldown), `@vitejs/plugin-legacy` 8.2 builds the polyfill chunk with Rolldown's
  CommonJS wrapper, which contains arrow functions, and the default Oxc minifier emits template literals, so
  `es-check es5` fails. Vite 7.3 + plugin-legacy 7.2 (Rollup + Babel + Terser) produce a clean ES5 legacy bundle.
  Follow-up: retry Vite 8 once plugin-legacy downlevels the polyfill chunk.
- **TypeScript 6.0**: `typescript-eslint` 8 supports TS `<6.1`, so TS 7 isn't usable yet.
- **`@playwright/test` pinned to 1.56.1** so that it matches the Chromium build preinstalled in the cloud dev
  environment (browser downloads are blocked there).
- **Playwright projects**: `ereader-small-{chromium,webkit}` (600×800), `ereader-large-{chromium,webkit}` (1072×1448),
  all with touch and `reducedMotion: 'reduce'`, plus `desktop` (Chromium). WebKit projects run when `CI` is set or
  `PW_WEBKIT=1`, because WebKit can't be installed in every dev environment; CI always runs all five.
- E2E runs against the production build (`vite preview`) so both the modern and legacy bundles are exercised by the build.
  The Chromium/WebKit browsers load the modern bundle; the legacy bundle is only checked by `es-check`
  (real-device validation comes with S0.3).
- Legacy targets: `defaults, safari >= 5, ie >= 11` (ES5 + core-js polyfills). `base: './'` so the build works under
  the GitHub Pages sub-path (S0.2).
- Lint gates: stylelint bans `display: grid`, `grid-*`, `var()`/`env()`, custom properties, `animation*`,
  `transition*` and `@keyframes`. ESLint bans `localStorage`/`sessionStorage` outside `src/storage/`.
  Prettier ignores Markdown to avoid reformatting the spec and stories.
- The placeholder page's two strings are not translated: the i18n framework arrives in S0.5 and the page is replaced
  by the shell in S0.4.
