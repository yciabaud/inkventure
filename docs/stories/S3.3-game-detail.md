## User story

As a reader, I want a detail page for each game so that I can decide whether to play it.

## Scope

- Load `games/<tuid>.json`; show cover, metadata, sanitized blurb (paginated if long), badges (format, experimental, may be slow).
- Actions: Play/Continue, Add to/Remove from Home (writes `ik:v1:home`).
- Credits: IFDB link, IF Archive link, licence if known.
- Cold-start deep link support.

## Acceptance criteria

- [ ] All fields render for sample games; Add to Home persists; Play navigates to reader.

## Required tests

**Unit (Vitest)**

- Blurb sanitizer (HTML → paragraphs), home list add/remove.

**E2E (Playwright)**

- From library open a game, add to home, reload, still added; deep link cold start works.

Plus the global gates: lint, `es-check es5` on the legacy bundle, CI green.

## Out of scope

- Reviews display.
