## User story

As a reader, I want a detail page for each game so that I can decide whether to play it.

## Scope

- Load `games/<tuid>.json`; show cover (IFDB thumbnail `&thumbnail=WxH` sized for the slot, never full size — SPEC §5.6), metadata, sanitized blurb (paginated if long), badges (format, experimental, may be slow).
- Actions: Play/Continue, Add to/Remove from Home (writes `ik:v1:home`).
- Credits: IFDB link, IF Archive link, licence if known.
- Cold-start deep link support.

## Acceptance criteria

- [x] All fields render for sample games; Add to Home persists; Play navigates to reader.

## Required tests

**Unit (Vitest)**

- Blurb sanitizer (HTML → paragraphs), home list add/remove.

**E2E (Playwright)**

- From library open a game, add to home, reload, still added; deep link cold start works.

Plus the global gates: lint, `es-check es5` on the legacy bundle, CI green.

## Out of scope

- Reviews display.

## Notes & decisions

- **Code**: `src/catalog/game.ts` (`loadGame`, `blurbParagraphs`, `thumbnailUrl` moved from the Library,
  `isIfArchive`), `src/storage/home.ts` (`ik:v1:home`: add at the top, remove, keeps saves), `GameScreen.tsx`.
- **Blurb**: IFDB descriptions are HTML (mostly `<br>`, `<i>`, `<a>`, `<p>`, entities). Every line break or block
  element starts a paragraph; other tags keep only their text; scripts, styles and comments are dropped (one pass
  over the text, not chained regex replacements, which CodeQL flagged as incomplete sanitisation); entities
  decoded; the result is rendered as text, never as HTML. **Paged** with CSS columns as wide as the blurb area (one
  column per page, counted from the position of an empty marker after the last word, since WebKit does not widen `scrollWidth` for overflowing columns;, re-counted when web fonts load), turned with the pager buttons.
- **Continue** when the game has an autosave. **Play** goes to `#/play/<tuid>`, which still shows the reader
  placeholder for catalogue games until S3.4 loads their files.
- **Home record**: entries keep title and author so My adventures (S4.2) can list them without the catalogue.
  "Storage full" on Add shows a message instead of failing.
- **Not shown**: licence (not in the catalogue data yet), forgiveness (not in IFDB's JSON API), the "Start here"
  badge (not in the detail; could come from `featured.json` / the index `st` in S4.1). Follow-ups.
- **Missing game**: a 404 for `games/<tuid>.json` (stale link) shows "Adventure not found" with a link to the Library;
  other errors offer Retry.
- **Tests**: unit `game.test.ts` (sanitizer, thumbnail, IF Archive links, loading and 404), `home.test.ts`. E2E
  `game-detail.spec.ts`: library → detail with every field, Add to Home survives reload (and Remove), Play → reader,
  cold-start deep link, Continue with a save, unknown game, long blurb paged without scrolling.
