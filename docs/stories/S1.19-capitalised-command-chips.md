## User story

As a player on an e-reader, I want to tap the commands a game tells me about ("type GUIDE", "HINT for help"), so
that I don't type them on the virtual keyboard.

## Background

Reported by the owner on 2026-10-02, after S1.12. Games often name their own commands in capitals, and these
commands are not among the command bar's directions and verbs:

- **Repeat the Ending** (`eueqjtej7bvnfp5a`, Glulx): `GUIDE` and other commands written in capitals.
- Common elsewhere: `HELP`, `HINT` / `HINTS`, `ABOUT`, `CREDITS`, `INFO`, `TALK TO`, `THINK`, `RECAP`.

Today the only way to send one is to tap the word in the text: it goes into the field in lower case (`wordAt` +
`insertWord`), and then Enter must be tapped. A multi-word command (`TALK TO`) takes several taps.

## Scope

- While the game waits for a **line**, read the commands the text names in capitals, in the paragraphs since the
  last command (and, on the first turn, the intro):
  - a run of 1–3 words in capitals, each of at least 2 letters (`GUIDE`, `TALK TO`, `X ME`);
  - stronger signal (listed first): the run follows `type`, `try`, `enter`, `say`, `use the command`, `tapez`,
    `essayez`, `la commande`, or is quoted (`"GUIDE"`, `[GUIDE]`).
- **Not commands**: the game title and headings (a paragraph that is entirely in capitals, the `header` / `subheader`
  styles), the room name and the status rows, words in capitals for emphasis inside a sentence with no signal
  (choose and record the rule: e.g. only a run that has a signal, or that the game repeats, or that is a known
  verb), Roman numerals, single letters, and words the command bar already has (`LOOK`, `INVENTORY`, `N`…).
- The chips go in the **verbs row**, before the usual verbs (they push the others into "More…", as narrow screens
  already do). A chip shows the command as written and sends it in lower case. At most 4 such chips; the rest stay
  reachable by tapping the word.
- They go away at the next turn when the new text names none (like the noun chips).
- SPEC §3.6 (Command input) updated.

## Out of scope

- Yes / no and numbered answers ([S1.17](S1.17-contextual-answer-chips.md)).
- Single-key prompts ([S1.12](S1.12-single-key-prompts.md)).
- Commands named in lower case in the prose (too many false positives).

## Notes & decisions

- **Rule for words in capitals with no signal:** a run gets a chip only with a signal — a cue before it (`type`,
  `typing`, `try`, `enter`, `say`, `use`, `command`, `tapez`, `essayez`, `commande`…), a mark around it (quotes,
  `[ ]`, `* *`, `( )`), `command` / `commande` after it, a placeholder after it (`someone`, `something`,
  `quelqu'un`…), or a cue earlier **in the same sentence** with "or" / "and" / "," before it ("Type WAKE UP if you
  feel sleepy, or LOGBOOK…"). The only exception is a short list of usual meta commands named alone (HELP, HINT(S),
  ABOUT, CREDITS, COPYRIGHT, INFO, INTRO, INSTRUCTIONS, VERBS, MENU, GUIDE, AMUSING, AIDE, INDICE(S)…). Emphasis
  (`You are NOT alone.`) has none of these, so it gets no chip. Repetition was not used: emphasis repeats too.
- **Never a chip:** SAVE, RESTORE, RESTART, QUIT, Q, UNDO, SCRIPT and their French forms (the menu already has them,
  and a stray tap must not reset the game); a run with a Roman numeral of 2+ letters (`ACT II`); what the bar already
  has, abbreviations included (L, I, X, Z, G, INV…).
- **Placeholder:** `TALK TO someone` / `WAVE AT someone` gives a `WAVE AT…` chip that fills the field (like the
  "…" verbs) instead of sending.
- **Order:** announced / marked commands first, then the meta commands, each in order of appearance; at most 4.
- **Where it reads:** the paragraphs since the last command (at most 20, replaced screens left out), only while the
  game waits for a line; the room name and the status rows are excluded, as are paragraphs entirely in capitals and
  `header` / `subheader` runs.
- **Fixture:** `lamp.inf` gets TIPS ("Type WAKE UP if you feel sleepy, or LOGBOOK to read the keeper's log."): WAKE
  UP is a multi-word command the Inform library answers, LOGBOOK the existing menu. `hints` was taken (HELP) — hence
  `tips`.
- **Survey on real games** (2026-10-03, headless, each line prompt of a short session, chips shown):

  | Game | Chips |
  |---|---|
  | Repeat the Ending | intro: GUIDE, ADVISORY, INSIDE, PS 1; after HELP: GAMEPLAY, VERBS, GUIDE, GD |
  | Lost Pig | HELP (intro) |
  | Violet | ABOUT, HINTS; after ABOUT: FEMALE, HETERONORMATIVITY OFF, CREDITS, COPYRIGHT |
  | Bronze | HELP (after the first yes) |
  | Anchorhead | HELP, ABOUT |
  | Photopia, 9:05, The Impossible Bottle, Eat Me, The Bat | none |
  | Counterfeit Monkey | none on the intro and its questions; TUTORIAL OFF on look, inventory, x me |

  All of them are commands the game names (Repeat the Ending writes "typing *ADVISORY.*", "type *GAMEPLAY*", "the
  *VERBS* command"). Ordinary turns of Lost Pig, Bronze and Photopia leave the verbs row unchanged.
- **Counterfeit Monkey, TUTORIAL OFF:** its tutorial ends ordinary turns with "If you do not want help getting
  started, type TUTORIAL OFF." It is announced with "type" and is a real command, so the chip is kept on purpose (a
  tap turns the tutorial off, and the chip goes with it). Not a title, heading, room name or emphasis.
- **Kindle check:** not done before the PR; to check on the preview and the Kindle (Repeat the Ending: GUIDE; Bronze:
  HELP after the first yes; a bold chip pushing Look into "More…" on the 6" screen).
