## User story

As a developer, I want a probe page that reports what the e-reader browser supports so that the assumptions in SPEC §2.2 are replaced by facts.

## Scope

- Standalone ES3/ES5 page `public/probe.html` (no framework, no build dependency).
- Detects and displays: user agent, viewport/devicePixelRatio, ES features (Promise, fetch, arrow functions via `new Function`, typed arrays), XHR `arraybuffer`, localStorage (write/read, approximate quota), IndexedDB, Service Worker, CSS flexbox/grid/variables/filter, touch & swipe events, font loading, `Intl`.
- Timing micro-benchmark (e.g. 1e6 loop iterations, JSON.parse of a 150 KB file).
- Tests XHR to IF Archive (a known small file) and to IFDB API to record CORS behaviour.
- Result shown as a copyable text block (to paste into an issue) and a large QR code of the result if feasible.

## Acceptance criteria

- [ ] Probe runs on the Kindle experimental browser without script errors.
- [ ] Results for at least one Kindle and (if available) one Kobo recorded in `docs/device-reports/` and SPEC §2.2 / §13 updated accordingly.
