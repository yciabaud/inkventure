## User story

As a player, I want the library to only show games I can actually play, without adult content, so that every tap on Play works.

## Scope

- Fetch `viewgame?json` per candidate; extract links, formats, IFID, genre, language, forgiveness, tags, cover, playtime.
- Choose the best playable file (format priority, IF Archive preference, zip containing a single story file).
- Compute `slow` flag (heuristic from S1.7 or provisional: Glulx > 1 MB).
- Content policy: `CONTENT_POLICY` env, tag denylist + manual exclude list in `scripts/catalog/content-policy.json`.
- Report of dropped games with reasons.

## Acceptance criteria

- [ ] Every kept game has a supported file URL; adult-tagged fixtures are excluded; report lists reasons.
