## User story

As a first-time visitor, I want a welcoming home with recommended games so that I can start playing immediately.

## Scope

- Featured shelf from `featured.json` with pitch in UI language, starter badge, horizontal paging with ‹ › buttons.
- First-launch empty state: welcome text, "How to play" help page, Featured first.

## Acceptance criteria
