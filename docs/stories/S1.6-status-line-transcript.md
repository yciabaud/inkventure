## User story

As a player, I want to see where I am and reread what happened so that I don't get lost.

## Scope

- Status line in the reader header (location · score/turns) from the Glk grid window / Z status.
- Transcript screen: full session history, paginated, read-only, jump to start/end.
- Transcript persisted with the autosave (tail capped, e.g. last 200 blocks).

## Acceptance criteria

- [x] Status line updates every turn in the fixture game.
- [x] Transcript survives reload (capped tail).

## Required tests

**Unit (Vitest)**

- Status extraction from Glk grid updates; transcript capping.

**E2E (Playwright)**

- After moving rooms, status line shows new location; transcript lists previous commands.

Plus the global gates: lint, `es-check es5` on the legacy bundle, CI green.

## Out of scope

- Transcript download/export.

## Notes & decisions

- **Status line**: already drawn by S1.3 (the Glk grid window → `status` blocks → `splitStatus`: location on the left,
  score / moves on the right, from the first row). This story adds the bridge-level unit tests and the e2e check that it
  follows the player from room to room.
- **Transcript view**: "Transcript" in the reader menu swaps the game's pages for a read-only `PagedText` over the same
  blocks (the whole session held in memory), opening on the last page. `PagedText` gained a `pageSlot` render prop
  (shown on every page, with first / last navigation) for it; « Start, End » and "Back to the game" sit there, and
  fit a 360 px phone. Returning to the game opens on the page of the last command.
- **Persisted tail**: the tail saved with the autosave and slots is now the last 200 paragraphs *with text* (blank lines
  between them are free), at most 20,000 characters (was 80 paragraphs / 8,000 characters). SPEC §4.4 updated.
- **Follow-ups**: Help and Game info in the reader menu (SPEC §3.6) are not part of any story yet; a compact
  "Turn 12" form of long score lines on narrow screens.
