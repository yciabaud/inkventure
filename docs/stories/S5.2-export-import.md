## User story

As a player with several devices, I want to export my saves as a code and import it elsewhere so that I never lose progress.

## Scope

- Export: compressed JSON of prefs/home/progress/saves → base64 in readable chunks; copy button; `.txt` download when supported.
- Import: paste code, validate (version, checksum), preview, merge or overwrite.
- Optional reminder to export after N named saves.

## Acceptance criteria

- [ ] Export on one profile + import on a fresh one restores home, progress and saves exactly.

## Required tests

**Unit (Vitest)**

- Codec round-trip, checksum failure, merge vs overwrite rules, version mismatch.

**E2E (Playwright)**

- Export in context A, import in fresh context B, Continue resumes the same turn.

Plus the global gates: lint, `es-check es5` on the legacy bundle, CI green.

## Out of scope

- Cloud sync.

## Notes & decisions

- **Dropped from V1** (2026-09-30), after a full implementation (closed PR #41: codec with checksum, merge /
  overwrite, copy, `.txt` download and file import, unit and e2e tests). On an e-reader it does not earn its place:
  a code with one Z-machine autosave is tens of KB, so it only travels by copy-paste or a file, which the Kindle's
  browser is unlikely to support; and the risk it covers (the browser clearing its storage) is low. The code stays
  reachable from PR #41 if the need comes back; see [post-v1-ideas.md](../post-v1-ideas.md).
