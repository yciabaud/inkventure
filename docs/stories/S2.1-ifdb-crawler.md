## User story

As the maintainer, I want a polite crawler of the IFDB API so that the catalogue can be rebuilt automatically.

## Scope

- `scripts/catalog/crawl.ts`: paginated `search?json` queries per supported system/format with `downloadable:yes`; ≤ 1 req/s, identifying User-Agent, retries with backoff.
- Incremental mode using a cache of previously fetched records (keyed by tuid + page version).
- `--record` mode saving responses as fixtures; `--offline` mode reading fixtures.
- Raw output `data/raw/*.json` (gitignored or on data branch).

## Acceptance criteria

- [ ] Offline run on fixtures produces a deterministic raw dataset.
- [ ] Live run documented; never executed in PR CI.
