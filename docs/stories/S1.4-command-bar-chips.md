## User story

As a player on an e-reader, I want to play most turns by tapping so that I rarely need the virtual keyboard.

## Scope

- Command bar (field + Enter) that survives the virtual keyboard (layout shrinks, re-pagination).
- Chips: compass (popover on small screens), verbs (Look, Inventory, Examine…, Take…, Drop…, Open…, Talk to…, Wait, Again, Undo).
- Verb tables per game language (EN, FR at minimum; ES/DE/IT stubs).
- Noun chips from recent output (heuristic extraction: capitalised/nouns from last N blocks, status line) + tap-a-word-to-insert in transcript.
- Command history prev/next.

## Acceptance criteria

- [x] A player can walk and pick up an object in the fixture game using taps only.
- [x] Verb chips switch to French for a French game (game language from metadata).

## Required tests

**Unit (Vitest)**

- Noun extraction on sample outputs (EN/FR), verb table selection, command composition.

**E2E (Playwright)**

- Tap `N` sends `north`; tap `Take…` then a noun chip sends `take <noun>`; tapping a transcript word inserts it.

Plus the global gates: lint, `es-check es5` on the legacy bundle, CI green.

## Out of scope

- Autocomplete from game dictionary (possible later enhancement).

## Notes & decisions

- **Layout**: a fixed-height slot (`reader__slot--game`, 196 px) on every page, so the text area keeps its size:
  directions row (N S E W Up Down + ⋯ dialog with all twelve), verbs row (Look, Inventory, Examine…, Take… + "More…"
  dialog with the other verbs and history), command field. After a "…" verb the verbs row becomes the noun row (+ ✕).
  Chips never wrap: labels shrink with an ellipsis. SPEC §3.6 rewritten to match.
- **Vocabulary** (`src/reader/commands/verbs.ts`): tables for EN, FR (Inform 6 standard / French library words),
  ES, DE, IT (`verified: false`, stubs to check with real games). `verbTable()` accepts codes or names, English by
  default.
- **Nouns** (`nouns.ts`): phrases after an article up to punctuation, a stop word, a verb form (EN `-ed`/`-ing` after
  the first word) or another article; head noun = last word (EN, DE) or first (FR, ES, IT), cut before "of"/"de";
  directions, verbs and the room name excluded; last 12 paragraphs, newest first, at most 8. A heuristic: some
  noise ("foot", "fixture") is accepted.
- **Composition** (`compose.ts`): chips send or fill the field; a noun completes a waiting verb and sends; tapped
  words are cleaned and lower-cased; history browsing.
- **Tap a word** (`src/reader/wordAt.ts`, `caretPositionFromPoint` / `caretRangeFromPoint`): the page turner now
  passes the tap point to `interceptTap`; on the last page while a line is awaited, a tap on a word goes to the
  field instead of turning the page.
- **Keyboard**: `PagedText` `pinToLast` (field focused) keeps every re-layout on the last page.
- **Game language**: fixture metadata says `en`; `?lang=xx` overrides it on fixture routes until S3.3 provides the
  catalogue language — this is how the French chips are tested.
- **Tests**: unit (verb tables, noun extraction EN/FR, composition, history); e2e `commands.spec.ts` (N sends
  north; Take… + noun chip; ✕; tapped word inserted / completing Examine…; French chips; both dialogs; history via
  dialog and arrows; shorter viewport keeps the field on the last page — verified to fail without `pinToLast`).
- **Not done**: autocomplete from the game dictionary (out of scope); the "▸ more" marker (still S1.6).
