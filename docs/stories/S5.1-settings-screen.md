## User story

As a user, I want a settings page so that I can change language, reader defaults and manage my data.

## Scope

- UI language selector (EN/FR) persisted.
- Reader defaults (same controls as Aa).
- Storage usage summary; reset all data (double confirmation).
- About: version, credits (IFDB, IF Archive, engines and licences), privacy statement.

## Acceptance criteria

- [x] Language switch applies immediately and persists; reset clears all `ik:` keys only.

## Required tests

**Unit (Vitest)**

- Storage usage computation, reset scope.

**E2E (Playwright)**

- Switch to French, reload, UI still French; reset returns to first-launch state.

Plus the global gates: lint, `es-check es5` on the legacy bundle, CI green.

## Out of scope

- Export/import (S5.2).

## Notes & decisions

- **Pages, not a long form:** the first page holds the language choice and links to three section pages
  (`#/settings?s=reading|data|about`), each with a "‹" back to the first page in its title. Every page fits on the
  baseline 636×740 viewport and on the 1280×720 desktop project without scrolling (e2e checks it, in French too).
- **Language:** Automatic / English / Français (language names in their own language). Automatic removes the saved
  override (`changeLocale(store, undefined)`); a change re-renders at once through `useLocale`.
- **Reader defaults** reuse the "Aa" controls, extracted as `ReaderSettingsForm` (and `Choice`) in
  `TextSettings.tsx`. A preview line uses the same text style; it has a fixed height and is clipped at the largest
  sizes so the page never scrolls.
- **Storage usage:** `store.usage()` (pure `computeUsage` in `src/storage/usage.ts`) counts characters (keys + values,
  as browsers count the quota) of every `ik:` entry, grouped as named saves, autosaves, cached story files and the
  rest. The screen shows KB/MB (Ko/Mo in French) against "about 5 MB", the usual quota (the Kindle measured 4.75 M
  characters). The storage-full banner's "Manage data" now opens `?s=data`.
- **Reset:** two dialogs (Continue, then Delete everything; Cancel at either step keeps everything).
  `store.clearAll()` removes every key starting with `ik:` — any schema version, `ik:schema` and `ik:probe`
  included — and nothing else; then the locale is re-detected and Home is shown as on a first launch, without a
  reload (`ik:schema` is written again on the next start).
- **About:** version = short commit and build date from the `inkventure-build` meta tag ("Development version"
  without it); credits (IFDB, IF Archive/IFTF, ZVM, GlkOte, Preact, fflate, Literata, Source Sans 3 with licences)
  and the privacy statement as paged paragraphs. Engines not shipped yet (Quixe, inkjs, Twine) are to be added to
  `about.engines` by S1.7–S1.9.
