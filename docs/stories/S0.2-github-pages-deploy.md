## User story

As the project owner, I want every merge to main deployed to GitHub Pages so that I can test the app on a real e-reader.

## Scope

- Workflow building and deploying `dist/` to GitHub Pages on push to main.
- Correct `base` path configuration for Pages (project site) and hash routing assumption.
- Build info (commit SHA, date) exposed in a `version.json` and in the page `<meta>`.

## Acceptance criteria

- [ ] After merge, the site is reachable at the Pages URL and loads the legacy bundle on an old browser.
- [ ] `version.json` matches the deployed commit.
