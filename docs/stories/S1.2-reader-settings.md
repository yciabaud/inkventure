## User story

As a reader, I want to choose font size, typeface, margins and spacing so that reading is comfortable on my device.

## Scope

- Reader menu (tap status line / ⋯) with Aa panel: 6 font sizes, serif/sans/dyslexia-friendly typeface, 3 margins, 3 line spacings, left/justified.
- Persist as defaults in prefs, optional per-game override.
- Refresh screen action in the menu.

## Acceptance criteria

- [x] Changing any setting re-paginates immediately and persists after reload.
- [x] Menu fully usable with taps, all controls ≥ 48 px.

## Required tests

**Unit (Vitest)**

- Settings reducer / persistence mapping.

**E2E (Playwright)**

- Change font size → page count changes and persists after reload.

Plus the global gates: lint, `es-check es5` on the legacy bundle, CI green.

## Out of scope

- Save/restore entries of the menu (S1.5).

## Notes & decisions

- **Menu**: the top zone still opens the app's top bar (Home, Library, Settings, Menu), now followed by a reader row
  with **Aa Text settings** and **Refresh screen**; save, transcript and help join it in S1.5 / S1.6.
- **Aa dialog** (`src/screens/reader/TextSettings.tsx`): size A− / "n / 6" / A+ (14, 16, 18, 21, 24, 28 px), typeface
  (Serif = Literata, Sans-serif = Source Sans 3, Easy reading), margins (12 / 24 / 48 px), line spacing (1.3 / 1.5 /
  1.8), alignment (left / justified), "For this game only". Segmented buttons with `aria-pressed`, all ≥ 48 px.
- **Model** (`src/reader/settings.ts`): `normalize` (any stored value → valid settings), `stepSize`, `textStyle`
  (inline style of the text area — the measurement layer is created inside it and inherits it), `settingsKey`;
  defaults in `prefs.reader`, per-game override in `progress:<tuid>.reader` (the rest of the record is kept).
  Hook `useReaderSettings(tuid)`; turning "For this game only" on copies the current look, off goes back to defaults.
- **Re-pagination**: `PagedText` `textStyle` + `layoutKey`; a new key calls `PageTurner.refresh()` (full re-measure,
  reading position kept). A new typeface's font is loaded and re-laid out through the existing font handling.
- **Easy reading**: no bundled dyslexia font — OpenDyslexic is 128 KB (woff), over the 80 KB font budget; uses
  Verdana / Tahoma / Trebuchet MS when present, else Source Sans 3, with 0.05em letter and 0.12em word spacing. Adding
  OpenDyslexic would need a higher budget: the owner decided (2026-09-30) not to raise it, so it stays out.
- **Tests**: unit (normalize, steps, style mapping, key, persistence of defaults and overrides). E2E
  (`settings.spec.ts`): A+ twice → more pages, persisted after reload (24 px); each setting re-paginates exactly like a
  fresh load with the same saved settings, and the page fits; per-game override leaves the fixture game at 18 px and
  unticking restores defaults; Refresh screen in the menu; dialog controls ≥ 48 px. A first version asserted "more
  pages" after each change, which is not always true (a narrower typeface and looser lines can cancel out) — replaced
  by the fresh-load comparison.
