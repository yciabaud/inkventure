## User story

As a player, I want to try Twine stories so that popular choice-based games are available too.

## Scope

- Load Twine HTML into `<iframe sandbox="allow-scripts">` via blob/srcdoc.
- Inject e-ink stylesheet and page-turn helper; fallback to scrolling inside the iframe if pagination fails.
- "Experimental" badge; Inkventure save slots disabled; story format's own save used.
- Twine fixture (Harlowe and SugarCube samples).

## Acceptance criteria

- [ ] Both fixtures readable and playable to an ending on the ereader projects.
- [ ] No script from the story can access the parent page (sandbox verified).

## Required tests

**Unit (Vitest)**

- Stylesheet injector and HTML preparation helpers.

**E2E (Playwright)**

- Open Harlowe fixture, click a link, text changes; parent storage untouched.

Plus the global gates: lint, `es-check es5` on the legacy bundle, CI green.

## Out of scope

- Full pagination for every story format.
